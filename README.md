# Tic-Tac-Toe Game

Welcome to the **Tic-Tac-Toe** game! This project is a premium, interactive implementation of the classic grid-based game, featuring a modern range of improvements including a **Play vs Computer** mode, a sleek **Dark Theme**, and **3D UI interactions**.

## Features

- **🏆 Play vs Computer**: Challenge our smart AI opponent that tries to win or block your moves!
- **👥 2-Player Mode**: Classic PvP mode to play with a friend on the same device.
- **🌑 Dark Theme**: A premium perception-aligned dark mode (`#121212`) for a comfortable gaming experience.
- **🧊 3D UI Interactions**: Tactile 3D buttons and game tiles with satisfying "press" animations and shadows.
- **📱 Responsive Design**: Optimized layout that looks great on both desktop and mobile devices.
- **Validation**: Alerts users if names are missing or turn selection is skipped.
- **About Me Section**: A stylish side-panel revealing details about the developer.

## Technologies Used

- **HTML5**: For semantic structure.
- **CSS3**: For custom 3D styling, animations, and responsive layout.
- **JavaScript (ES6+)**: For game logic, AI opponent (PvC), and DOM manipulation.
- **Lite-Server**: For a lightweight local development server.

## Installation

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Harendrasingh1/tic-tac-toe.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd tic-tac-toe
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```
   *(This installs `lite-server` for the best local experience)*

4. **Start the Game:**
   ```bash
   npm start
   ```
   This will automatically open the game in your default web browser at `http://localhost:3000`.

## Usage

1.  **Select Game Mode**: Choose between **2 Players** or **vs Computer** at the top.
2.  **Enter Names**: Input names for the players (Player 2 is auto-set to "Computer" in PvC mode).
3.  **Choose Turn**: Select who goes first (Player 1 or Player 2/Computer).
4.  **Start Game**: Click the "Start Game" button.
5.  **Play**: Click on the 3D tiles to place your symbol (X or O).
6.  **Reset**: Use the "Reset Game" or "New Game" buttons to restart anytime.
